# CUDA Nsight Compute Profiling

This repository documents my profiling and performance analysis of CUDA SGEMM kernels using NVIDIA Nsight Compute.

The kernels themselves are developed separately in my FP32 SGEMM optimization repository. This repository focuses on understanding their GPU behavior through profiling.

## Goals

- Learn NVIDIA Nsight Compute systematically
- Profile each SGEMM kernel as it is developed
- Identify performance bottlenecks
- Understand important GPU metrics
- Understand trade-offs and decision making
- Document profiling-based optimization learnings
